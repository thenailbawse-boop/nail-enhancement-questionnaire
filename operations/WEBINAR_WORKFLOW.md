# Webinar workflow: Booked, Burnt Out & Underpaid (evergreen version)

The funnel is in `funnel/`: one signup link → one list → one 3-email flow → one recurring Zoom.
Nothing changes per workshop, so there's no per-event setup. (This replaces the per-event list + flow version.)
**Who does what:** 🤖 = Claude · 👑 = you.

## One-time setup
Follow `funnel/README.md` → "One-time setup". Then run the test below before switching the flow to Live.

## Test protocol (at setup, and after any edit to the flow, page or Zoom)
1. Sign up through the public link with `thenailbawse+test-<date>@gmail.com`.
2. 🤖 checks Gmail: Email 1 arrives within minutes, the Zoom link opens the right meeting, and the copy has no leftover placeholders.
3. 🤖 checks again Thursday 3 PM (Email 2) and Friday 10 AM (Email 3).
4. Result goes in DASHBOARD.md. **Never call it working without this.**

## Every week
| When | Who | What |

## Monthly (5 min)
🤖 reports: signups, show-up rate (once Zoom is connected), replies to Email 3, unsubscribes. You decide if anything changes.

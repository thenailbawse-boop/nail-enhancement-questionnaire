## 2. Layout

```
iphone-operator/
├── CreatorReset.xcodeproj      ← open this in Xcode (generated by tools/generate_xcodeproj.py)
├── App/                        ← iPhone app (SwiftUI, PhotoKit, Vision, App Intents, BackgroundTasks)
│   ├── Services/               ← OrganizerEngine (agent loop), PhotoLibrary, VisionLabeler, Storage, TestPhotoFactory, SelfTest
│   ├── AI/                     ← optional Apple on-device model with tool calling (iOS 26+)
│   ├── Intents/                ← Shortcuts actions
│   └── Views/                  ← Home, Review, Results, Ask, Help
├── SafariExtension/            ← Safari Web Extension target (native handler + Resources/ JS)
├── Shared/                     ← code used by both targets
├── Core/                       ← platform-free logic + Swift unit tests (swift test, runs on Mac or Linux)
├── web-tests/                  ← Node tests for the Safari scripts (npm test)
└── tools/                      ← project generator, project checker, icon generator
```

Targets: `CreatorReset` (iOS app, iOS 17.0+, iPhone) embeds `CreatorResetSafari` (Safari web extension).
Bundle IDs come from one setting, `CR_BUNDLE_PREFIX` (default `com.thenailbawse`).
No entitlements, App Groups, servers, accounts or paid services are required.

## 3. The agent loop (Photos)

`OrganizerEngine.run` = **observe** (PhotoKit metadata + on-device Vision on a 360 px thumbnail; iCloud-only originals are not downloaded) → **plan** (`MediaClassifier`: deterministic rules; uncertain → Needs Review; videos never "understood") → **authorize** (`RiskPolicy` + pause switch) → **execute** (add existing asset to album — no copies) → **verify** (re-read album membership) → **log** (`ledger.json`: asset ID, category, reason, confidence, before, after, outcome, error, permission, trigger).
Same engine is used by the Home screen, Shortcuts, background time and the AI assistant.

Risk tiers (`Core/Sources/OperatorCore/RiskPolicy.swift`):
- read-only: scan, classify, duplicate count, storage report, web inspect
- reversible (blocked when paused): create album, add to album, add fake test photos, web scroll/type/tap
- needs approval each time: remove the app's own fake test photos (iOS also confirms)
- **forbidden (not implemented):** delete user media, upload, Instagram archive/delete/publish, web submit/password/purchase

## 4. What is possible vs. impossible on iOS (public APIs only)

| Want | Reality | What we did |
| --- | --- | --- |
| See/tap any app like Claude in Chrome | **Impossible** for App Store–style apps. No public API. | Photos via PhotoKit; websites via Safari extension; other apps only through their own Shortcuts actions. |
| Run forever in background | **Impossible.** | Shortcuts Time-of-Day automation (most predictable) + optional `BGProcessingTask` (iOS decides). |
| Free storage automatically | Possible only by deleting, and iOS always asks the user. | Deliberately not implemented. App finds duplicates/long videos and points to Apple's Duplicates tool; tracks before/after free space honestly. |
| Exact file sizes per photo | No public API. | Uses video duration as the honest proxy ("longest videos"). |
| Archive/delete Instagram posts by API | Not offered by Meta's public Instagram API for this use. | Manual steps + Meta AI audit prompt; marked UNVERIFIED. |
| ChatGPT controlling the phone | No. ChatGPT can be used inside Shortcuts on Apple Intelligence devices. | `Get Library Report` returns text (numbers only) you can pass to ChatGPT in Shortcuts. |
| Free on-device AI | Yes on iPhone 15 Pro and newer with iOS 26 + Apple Intelligence. | Optional; the rule-based brain works on every iPhone. |

## 6. How to rebuild / test

```bash
python3 tools/generate_xcodeproj.py   # after adding/removing source files
python3 tools/check_xcodeproj.py      # structural check, no Xcode needed
(cd Core && swift test)               # 26 unit tests (Mac or Linux)
(cd web-tests && npm install && npm test)   # 8 Safari-script tests
# On a Mac:
xcodebuild -project CreatorReset.xcodeproj -scheme CreatorReset -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```
Simulator self-test (Debug builds only): launch with argument `-CRSelfTest`; results go to the app's `Documents/selftest.json`. It uses fake photos only. `.github/workflows/creator-reset-ios.yml` does all of the above on every push.
